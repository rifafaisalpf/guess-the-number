# 🎯 Guess the Number

A beginner-friendly Python number guessing game built while learning Python fundamentals.

## 🕹️ About the Game

The player chooses a difficulty level and tries to guess a randomly generated number within a limited number of attempts.

### Difficulty Levels

| Difficulty | Number Range | Attempts |
| ---------- | -----------: | -------: |
| Easy       |         1–50 |       10 |
| Medium     |        1–100 |        5 |
| Hard       |        1–200 |        3 |

## ✨ Features

* 🎯 Three difficulty levels
* 🎲 Randomly generated target number
* 🔢 Different number ranges
* ❤️ Limited attempts based on difficulty
* 💡 Hints when the guess is too high or too low
* 🚫 Validates guesses within the selected range
* 🔄 Option to play again

## 🛠️ Built With

* Python
* `random` module

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Clone or download this repository.
3. Run the Python file:

```bash
python guess_the_number.py
```

4. Choose a difficulty and start guessing!
